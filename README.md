# 媒体归类工具 GUI版

图形界面工具，自动区分照片/视频，按 `YYYY-MM-DD` 文件夹归类。
**零外部依赖**：不需要 ffmpeg，不需要任何额外工具，打包后的 exe 是纯单文件。

## ✅ 功能特性
- 图形界面：选择源目录、输出目录，一键归类
- 照片/视频自动分流到 `photo` / `video` 两个根目录
- 按日期创建 `YYYY-MM-DD` 文件夹（精确到天）
- 照片优先读取 EXIF 原始拍摄时间（苹果 HEIC 原生支持）
- 照片无 EXIF（截图、聊天传输图片常见）自动按文件修改时间归类，不再堆积在 unknown
- 视频按文件修改时间归类（无需 ffmpeg，零外部依赖）
- 预览模式：只输出日志、不复制文件，正式整理前先核对
- 递归扫描子文件夹开关；自动排除输出目录内的已归类文件，防止重复处理
- 预扫描统计媒体总数 + GUI 实时进度条
- 默认**复制文件**（不移动原始素材），保护源文件
- 任务完成自动保存运行日志到输出目录 `sort_log.txt`

## ✅ 支持媒体格式
| 类型 | 格式 |
| ---- | ---- |
| 照片 | jpg / jpeg / png / heic / heif / tiff / bmp |
| 视频 | mp4 / mov / mkv / avi |

## 📂 输出目录结构
```
输出文件夹/
├─ photo/
│   ├─ 2026-10-09/       # 有EXIF：按拍摄时间
│   └─ 2026-10-10/       # 无EXIF：按文件修改时间（截图/聊天图片）
├─ video/
│   ├─ 2026-10-08/       # 按文件修改时间归类
│   └─ 2026-10-10/
└─ sort_log.txt          # 本次运行日志
```

## 🚀 快速开始（源码运行）
1. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```
2. 运行：
   ```bash
   python main_gui.py
   ```

## 📦 打包成 EXE
在项目目录执行（Windows，已内置图标）：
```bash
pyinstaller -F -n MediaSorterGUI --icon "icon.ico" --add-data "icon.ico;." main_gui.py
```
- 打包产物为单个独立 `dist\MediaSorterGUI.exe`，自带程序图标
- 目标电脑不需要安装 Python，也不需要任何额外文件

文件夹模式（多文件，启动稍快）：
```bash
pyinstaller -D -n MediaSorterGUI --icon "icon.ico" --add-data "icon.ico;." main_gui.py
```

## ⚠️ 注意事项
1. 默认**复制文件，不移动原始素材**，不会丢失原始文件
2. 照片优先读取 EXIF 拍摄时间；无 EXIF 时使用文件修改时间归类（Windows 拷贝后修改时间仍保留原始拍摄时间，截图/聊天图片的修改时间≈生成时间，可靠）
3. 视频按文件修改时间归类：手机直接导出、未转存过的视频，修改时间基本等于拍摄时间；拷贝/转发多次的视频日期可能变成拷贝时间
4. HEIC 图片在 Windows 资源管理器预览需额外解码器，不影响本工具读取拍摄时间
5. 源目录与输出目录可以相同（输出自动落在其 photo/video 子目录，且不会重复扫描已归类文件）
6. `sort_log.txt` 每次运行会覆盖上一次的日志

## 🕐 时间读取逻辑
| 媒体类型 | 优先 | 兜底 |
| -------- | ---- | ---- |
| 照片 | EXIF DateTimeOriginal 原始拍摄时间 | 文件修改时间（直接归类到日期文件夹） |
| 视频 | 文件修改时间 | —— |
